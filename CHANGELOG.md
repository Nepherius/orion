# Changelog

All notable changes to Orion should be documented in this file.

## 1.2.5

- Added monthly external data refresh behavior with bundled asset fallback.
- Unified asset loading and validation for loadout equipment data.
- Improved loadout form resilience for malformed autocomplete options.
- Added analytics data quality warnings.
- Added analytics metric notes for formulas and assumptions.
- Added a main-view error boundary to avoid full black screens from isolated view errors.
- Improved panel consistency across the application.
- Added release scripts for Linux `deb`, `rpm`, `AppImage`, and Windows `msi` and executable installers.

## Earlier Versions

- Initial session, loot, loadout, chat log monitoring, and analytics functionality.
